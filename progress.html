Daily weigh-in: after using the toilet and before food/drink. Judge progress using the 7-day average.

Adjustment rules

  • 0.5–0.8 kg/week: keep calories.
  • >1 kg/week repeatedly + poor recovery: increase calories.
  • <0.3 kg/week for 2 weeks: reduce approximately 150–200 kcal/day.
Performance checks

Every 4 weeks.

Use performance to make sure the weight descent is supporting the boxing goal rather than undermining it.

Body

  • 7-day weight average
  • Waist measurement

Strength + athleticism

  • Strength performance
  • Broad jump
  • 10–20 m sprint

Boxing

  • 3 × 2 min controlled bag test
  • Round 3 vs round 1 output
  • Shoulder/arm function
  • Footwork quality under fatigue
Key fight test: 3 × 2-minute rounds with 1-minute rests. Round 3 should still show moving legs, fast hands, a functional guard, controlled breathing and intact decision-making.
